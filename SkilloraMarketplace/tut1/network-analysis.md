# Network Analysis — Skillora Tutorial 1

## Browser procedure

1. Open a website in Chrome/Edge.
2. Press F12.
3. Open **Network**.
4. Enable **Disable cache**.
5. Reload the page.
6. Record the number of requests, total transferred size, slowest resource, and any 3xx/4xx responses.

## Submission table

| Item | Value to record |
|---|---|
| Website | Skillora local frontend / chosen website |
| Request count | Record from Network panel |
| Total page size | Record from Network panel |
| Slowest resource | Record name and duration |
| 3xx responses | Record if present |
| 4xx responses | Record if present |
